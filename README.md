# Kalkulator Geometri Bangun Datar

## Deskripsi Proyek

Kalkulator Geometri Bangun Datar merupakan program sederhana berbasis Python yang dirancang untuk membantu pengguna menghitung luas dan keliling beberapa bangun datar.

Program ini dibuat sebagai proyek mata kuliah Algoritma dan Pemrograman, Program Studi Pendidikan Matematika FKIP Universitas Sultan Ageng Tirtayasa.

## Fitur

1. Menghitung luas dan keliling persegi.
2. Menghitung luas dan keliling persegi panjang.
3. Menghitung luas dan keliling segitiga.
4. Menghitung luas dan keliling lingkaran.
5. Memvalidasi input berupa angka positif.
6. Menangani pilihan menu yang tidak tersedia.

## Teknologi

- Python 3
- Visual Studio Code
- Git dan GitHub

## Persyaratan

- Git sudah terinstal.
